## What is callable

Cadence's flagship EDA tools are licensed desktop and compute software driven by
SKILL and Tcl scripting inside the installed product; they are not network APIs
and Cadence publishes no contract for them. Two HTTPS APIs and one identity
surface are real, reachable and documented, and one desktop scripting API is
distributed as a public Python package:

- Orion Molecular Design Platform API — https://orion.eyesopen.com
  Token-authenticated. The published interface is the `orionclient` Python
  library and the `ocli` CLI, not a REST reference. Programming guide:
  https://docs.eyesopen.com/orion-developer/index.html
- MMDS — Macromolecular Data Service — https://mmds.eyesopen.com/api/v1/
  A live JSON API (Django REST Framework). Every path is authentication-gated;
  an anonymous GET returns 403 {"detail":"Authentication credentials were not
  provided."}. Client API: https://docs.eyesopen.com/webservices/mmds/client.html
- Cadence Online Support OpenID Connect provider — https://support.cadence.com
  Discovery: https://support.cadence.com/.well-known/openid-configuration
- Fidelity Pointwise Glyph Server — a scripting API on a running Pointwise
  session, reached with the `pointwise-glyph-client` Python package.
